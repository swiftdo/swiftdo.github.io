# DSH Desktop 深度实战：10 款神级第三方插件推荐与盘点

随着 DeepSeek Harness (DSH) 成为许多全栈开发者与架构师的主力 AI 编程中枢，单纯依靠开箱即用的默认配置已无法满足复杂的长周期工程需求。通过 DSH 丰富的第三方插件生态，我们可以将其武装成一个兼备**超长上下文、跨会话记忆、多模型协同以及全功能 IDE 交互**的终极开发工作台。

本文精选了目前 DSH Desktop 环境中最值得安装的 10 款重量级第三方插件，逐一拆解它们的核心功能与解决的实战痛点。

---

## 一、模型与执行底座

### 1. Antigravity 模型接入 (ACP)
* **插件定位**：DSH 主模型接入方案，经 ACP v1 协议驱动本地官方 Antigravity CLI (`agy acp`)。
* **核心功能**：
  * 无缝桥接并调度外部顶级模型。
  * 保持 DSH 原生工具系统与工作区权限模型不变。
* **解决的痛点**：打破单一模型限制，轻松调动全球顶尖推理模型。
* **参考**：[官方 Antigravity 仓库](https://github.com/deepseek-ai/deepseek-harness)

### 2. dsh-ops
* **插件定位**：专为 DSH 打造的本地高性能原生 Rust 工具集与优化 Bash 运行环境。
* **核心功能**：提供原生的文件检索工具（如 `ops_grep`, `ops_glob`），返回极高紧凑格式的差异结果。
* **解决的痛点**：节省 Token，显著提升大工程扫描与检索的执行效率。
* **参考**：[DSH Ops 官方介绍](https://dshx.io/en/plugins/dsh-ops)

---

## 二、上下文治理与长期记忆

### 3. billion-context
* **插件定位**：下一代会话级上下文压缩与折叠插件。
* **核心功能**：将已完成的分析过程渐进式压缩为自包含摘要，支持单会话持续运行一个月。
* **解决的痛点**：告别会话中断，实现超长上下文，降低 Token 消耗。
* **参考**：[billion-context 官方文档](https://dshplugin.me/plugins/billion-context-dsh)

### 4. 主动联想记忆 (dsh-auto-memory)
* **插件定位**：Astra 架构的终极长期记忆管家。
* **核心功能**：自动沉淀对话决策、管理白板与交接账本、固化技能流程（Procedure Memory）。
* **解决的痛点**：解决“关掉会话就失忆”与多天长任务交接难的问题。
* **参考**：[NattoCB/dsh-plugin-memory 仓库](https://github.com/NattoCB/dsh-plugin-memory)

## 三、交互与开发者体验

### 5. Better Sidebar
* **插件定位**：现代化一体式右侧边栏工作台。
* **核心功能**：集成文件树、轻量编辑器与 Git Diff 视图，提供会话级隔离的工作区。
* **解决的痛点**：告别多窗口切换，实现 AI 对话与代码管理的一体化。

### 6. dsh-skill-mcp-panel
* **插件定位**：Skills 技能库与 MCP 服务器的综合控制台。
* **核心功能**：可视化管理 MCP 服务状态，提供一键启停与诊断能力。
* **解决的痛点**：使 MCP 服务状态透明化，便于快速排查与调优。

### 7. 插件市场
* **插件定位**：DSH 生态的一键式应用分发中心。
* **核心功能**：汇聚社区与官方插件库，支持分类筛选与安全安装。
* **解决的痛点**：极大降低功能扩展门槛，即点即用。

## 四、专业领域协同与外部赋能

### 8. dsh-free-search
* **插件定位**：聚合 27+ 引擎的免费联网搜索插件。
* **核心功能**：智能路由并行查询，提供带事实依据链的即时联网抓取。
* **解决的痛点**：解决大模型时效性盲区，快速获取库变更与技术解决方案。

### 9. Agency Agents
* **插件定位**：331 名垂直领域专精智能体即时召唤库。
* **核心功能**：覆盖安全、UI、架构等 22 个细分领域，支持专家团协同并行工作。
* **解决的痛点**：突破通用模型泛化瓶颈，获取工业级专业垂直领域产出。

### 10. dsh-hotspot
* **插件定位**：技术热点监控与自动化选题写作引擎。
* **核心功能**：自动化监测 GitHub Trending/HN/RSS，智能打分排序并一键生成标准 Markdown 草稿。
* **解决的痛点**：极大简化从选题收集到技术文章撰写的全流程闭环。

## 插件管理小贴士

DSH 的生态是开放且可管理的。如果您想探索更多功能，或管理当前环境，只需在终端使用以下指令：

```bash
# 查看所有已安装插件详情
dsh plugin --profile desktop list_plugins

# 安装新的第三方功能包
dsh plugin --profile desktop install_bundle <bundle-package-name>
```

**总结**：这 10 款核心第三方插件构成了 DSH 的高生产力矩阵。从底座工具加速到高阶记忆沉淀，它们让本地开发真正迈向专业级、工程级的全新阶段。
