# DeepSeek Harness 日活达154万，第三方插件超过3.5万个

DeepSeek Harness 的最新数据已经公布：日均活跃用户达到 154 万，公开的第三方插件约有 3.5 万个。材料显示，这一统计以使用官方 API 的用户为范围；上周日均活跃用户还是 140 万，最新数据已增至 154 万。团队同时提到，面向插件作者的支持计划正在筹备中。

## 从预览版到桌面端：用户与 Token 同步增长

DeepSeek Harness 在 8 月 13 日发布预览版，9 月 29 日发布桌面端。材料称，桌面端发布以来，使用量持续增长。最新日均活跃用户 154 万，比桌面端发布时增长 545%。材料还提到，看上去大家都很喜欢 V4.1-Flash-1017 这个模型。

Token 用量也在同步上涨：最近一周日均消耗 87.1 万亿，11 月 4 日当天为 92.1 万亿，比桌面端发布时增长 306%。这些数字与日活数据一起，构成了 Harness 当前增长情况的主要参照。

## 3.5 万个插件，约 60% 活跃用户用过

从 8 月 13 日预览版发布到现在，公开的第三方插件已有约 3.5 万个。材料注明，这一数字根据公开资料估算，并已去重。约 60% 的活跃用户制作或安装过至少一款第三方插件。

材料同时提醒，这些插件还在持续迭代，成熟度和适用场景各有差异。团队希望和开发者、用户一起，把它们打磨得更实用、更稳定。插件安装方式也比较直接：在 DeepSeek Harness 的插件安装页面输入包名，就能下载体验。

## 四款社区插件：把日常需求做成界面

团队这次介绍了四款社区插件，每款都有自己的界面。

自媒体创作者工作台（dsh-media-desk）作者为 GitHub 用户 woniuniuniu（小红书：蜗牛的科技笔记）。蜗牛把记灵感、写脚本、做封面、设计分镜都放进了一个工作台，界面延续了 DeepSeek Harness 的极简风格。蜗牛这样形容日常使用：“现在它已经变成我的日常工作台，睡醒、打开 DSH、秒开工作台、开蹬！”

歸藏设计（dsh-guizang-design）作者为 GitHub 用户 op7418（公众号：歸藏的 AI 工具箱）。歸藏把常用的设计和文字润色 Skill 合成了一个插件，能把一篇文章变成网页、图文卡片或封面。做好的内容存在“我的作品”里，可以通过“做同款”复用。从 Skill 换到插件，歸藏发现了更多创作空间：“DeepSeek Harness 的插件系统能给的比 Skill 多很多。通过我的设计插件，作品、专栏和语气都能积累下来，内容生成的质量会非常稳定。”

上下文洞察插件（dsh-context）作者为 GitHub 用户 bowenliang123（B 站：博文博文）。用这个插件，可以看到 Agent 工作时用了哪些信息，以及这些信息怎样随对话变化。内容从 Context 的组成和演进，一直讲到多 Agent 团队协作的关键细节。bowenliang123 评价：“DeepSeek Harness 的开放、灵活、强大的插件哲学，真正让一切变得可能，dsh-context 与 dsh 重新让每个 Agent 的上下文和 Harness 真正开源，并回到你的手中。”

论文阅读插件（agentero-dsh）作者为 Phil-Fan（小红书：PhilFan）。这个插件把 Agentero 接入了 DeepSeek Harness，读论文、做高亮、翻译、记笔记都在同一个地方完成，也可以请 Agent 帮忙梳理思路。这个想法来自 Phil-Fan 团队的科研日常：“很喜欢 DeepSeek Harness 灵活的插件机制，让我们能把文献管理、翻译和笔记串起来，做一款人和 Agent 用着都舒服的文献工具。”

## 插件作者支持计划与“一切皆插件”

材料称，团队接下来会继续投入几件事：提升插件 API 的稳定性和兼容性，完善插件安全机制，建设官方插件市场，方便作者上传插件，也方便用户找到需要的插件。

同时，团队正在筹备面向插件作者的支持计划，通过 token 激励、技术交流和作品推荐，支持新想法的探索和已有作品的完善。具体支持方式会结合社区的需求和反馈逐步完善。感兴趣的开发者可以填写意向报名表，分享作品、想法和需求；这次报名主要用于收集意向，参与规则和支持安排会在计划正式推出时公布。

团队希望 DeepSeek Harness 成为 Agent 时代的操作系统：提供稳定的基础能力，内置大多数人都需要的通用功能；专业场景、特定行业和个性化需求，交给最了解它们的开发者，用插件探索更贴切的解法。材料将这一方向概括为“一切皆插件”。
