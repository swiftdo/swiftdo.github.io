# Personal Agent

灵光2.0上线后，灵光团队做了一件不太像大厂常规动作的事：集体入驻小红书，连续发声。架构师讲 Agent Harness，产品经理解释灵光2.0为什么要成为“真正能管事的个人助理”，技术负责人谈的是让 AI 从“能回答问题”走向“能帮你管事”，算法工程师则直接晒用法——自动续费、预算跟进、持仓复盘、支付宝账单整理，以及政策简报和每日 AI 产品简报。

这些用法指向同一个词：Personal Agent。按灵光团队的说法，它要成为“真正能管事的个人助理”：重点不在“能回答问题”，而在“能帮你管事”——记住任务、跟上提醒，把事情替你办完。

这个动作本身，比任何发布会都更能说明蚂蚁对 Personal Agent 的押注决心。

## 从“闪应用”到私人秘书

灵光1.0还是一个生成小应用的工具。2025年11月18日产品正式上线，市场口号是“30秒生成闪应用”，用户不必懂代码，口述需求就能定制专属小工具。到了2.0，蚂蚁希望用户把事情交给它：记住任务、跟进提醒、成为用户的私人秘书。

这个位置在移动互联网时代属于支付宝。但在 AI 时代，这个位置还是未知的。能不能拿到这张牌，决定了蚂蚁能否从上一个时代顺利过渡到下一个时代。

灵光的起点并不低。2025年春节 DeepSeek 爆火后，蚂蚁从复工第一天起连开三天复盘会。集团 CTO 何征宇后来在媒体采访中提到，团队既兴奋又紧迫，甚至羞愧：百灵在部分模型技术上与 DeepSeek 起点相近，却因计算资源等原因晚了一步。3月，蚂蚁组建了相对独立的 AGI 项目组织；到11月灵光1.0上线时，这支团队已扩张到200多人，由何征宇直接负责，蔡伟担任灵光产品负责人。

当时 AI coding 赛道已跑出增长范例：瑞典创业公司 Lovable 在2025年7月23日对外宣布 ARR 突破1亿美元，从100万美元到破亿仅用八个月。灵光跟上的是这股生成应用的浪潮。何征宇、蔡伟在上线群访中坦言，3月敲定方向时团队都无法确定闪应用能否如期落地，做这件事本身就是一场赌注。最初内部预期并不高，目标只定到年底20万用户；据何征宇转述，马云看到这个目标觉得太差了，要求团队“往前冲击一下、冲个第一”。

## 短期爆发与长期留存的裂缝

灵光确实冲上去了。上线第三天下载突破50万，登顶 App Store 免费工具榜榜首，4天破100万，第六天超过200万。作为对照，材料提到 ChatGPT 上线首周下载不过60.6万，Sora2 突破百万也花了5天。

但短期用户的快速增长没能转化成长期成功。2026年3月，量子位智库数据显示，灵光新增用户三日留存仅有21.2%，同期豆包为30.92%、千问27.99%。QuestMobile 数据也显示，当时灵光已跌出国内 AI 应用月活前十。

4月20日，灵光往闪应用上加码，抛出1亿元创作者激励计划：单日最多奖励1万个优质应用，单条奖励100元；每周最多奖励100名创作者，单人最高1万元。领取激励的前提是作品公开发布在新上线的“灵光圈”。官方数据称，上线五个月，用户累计生成超3000万个闪应用。但闪应用的热度很快过去。2026年6月，市场消息称灵光“一号位”寒洛调岗支援阿福，多名技术骨干一同被抽调，蚂蚁未正式回应。

## 蚂蚁需要自己的Muse

秋天带来了另一个故事。9月8日，Meta 发布 Muse，直接下场帮用户干活：写邮件、规划行程、协商账单。SensorTower 统计，Muse 上线40天仅美国市场下载就达到1020万次。它把 Personal Agent 捧上 AI 神坛，也让 Meta 拿到一张能被市场看见的 AI 牌。

这正是蚂蚁眼下的处境。材料指出，蚂蚁的阿福和阿宝表现都很不错，但除去这些垂直产品，蚂蚁目前还没有一款通用 AI 产品，能像 Muse、豆包或千问那样，让用户在面对日常需求时第一时间想到它。产品场景不少，却还没有一款产品把这些能力集成为一个超级入口。

于是灵光2.0承担起这个角色。对蚂蚁来说，“灵光能不能做好”不是核心问题，及时下场尝试才是更重要的事。灵光团队希望借小红书的社区共创，给这款 Personal Agent 产品找到用户心目中的位置。

但阻力同样明确：材料提到接口受限、体验卡点频出，留存数据也不及竞品，具体受限范围与卡点细节尚未披露。蚂蚁在 AI to C 赛道同时押注阿宝、阿福与灵光，内部资源博弈与外部平台竞争交织。这场接替支付宝入口的赌局，才刚刚开始。
