## 什么是"纳天干地支"

十二经脉除命名外，还与**天干**（甲、乙、丙、丁、戊、己、庚、辛、壬、癸）、**地支**（子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥）相配合，这是**子午流注**针法"按时取穴"的理论基础：

- **纳天干（纳甲法）**：以天干配属脏腑经脉，按**日**干支推算开穴；
- **纳地支（纳子法）**：以地支时辰配属经脉流注，按**时**辰气血盛衰取穴。

## 一、十二经纳天干（纳甲法）

歌诀（何若愚《子午流注针经》，亦载于《针灸大成》）：

> 甲胆乙肝丙小肠，丁心戊胃己脾乡，
> 庚属大肠辛属肺，壬属膀胱癸肾脏，
> 三焦亦向壬中寄，包络同归入癸方。

### 配属原理

天干本身分阴阳、配五行（甲乙木、丙丁火、戊己土、庚辛金、壬癸水），脏腑亦按五行归属，故二者一一对应：

- **阳干配阳腑**：甲（阳木）配胆（木）、丙（阳火）配小肠（火）、戊（阳土）配胃（土）、庚（阳金）配大肠（金）、壬（阳水）配膀胱（水）；
- **阴干配阴脏**：乙（阴木）配肝、丁（阴火）配心、己（阴土）配脾、辛（阴金）配肺、癸（阴水）配肾。

可见纳干配属与五行完全一致，相表里的脏腑（如胆与肝同属木）分得阴阳相邻的两个天干。

> 注：三焦、心包非五行常配之脏腑，纳甲法将三焦**寄于壬**、心包**寄于癸**（徐凤《针灸大全》另有"三焦归丙、包络归丁"之说）。

### 配属原理

营气在十二经脉中"阴阳相贯，如环无端"昼夜运行，每时辰气血流注一经，周而复始。流注从**肺经（寅时）**开始——肺朝百脉，为一身之气的起始；其后按十二经流注次序（肺→大肠→胃→脾→心→小肠→膀胱→肾→心包→三焦→胆→肝→肺）逐时推进。

## 三、临床应用

**1. 纳子法——补母泻子取穴**

某经当令之时，气血正盛：实证泻其**子**穴，虚证补其**母**穴。以肺经为例（肺属金）：

- **实证**：泻子穴——**尺泽**（肺经水穴，金生水，水为金之子），于寅时泻之；
- **虚证**：补母穴——**太渊**（肺经土穴，土生金，土为金之母），于卯时补之。

**2. 纳甲法——按时开井荥输经合**

按日干支推出当日时干支，阳日阳时开阳经五输穴（阳井金），阴日阴时开阴经五输穴（阴井木），此为"子午流注纳甲法"开穴的核心。

**3. 养生作息——脏腑当令**

- **子时（胆）**：23 点前入睡，胆经当令宜熟睡；
- **丑时（肝）**："卧则血归于肝"，深睡以养肝血；
- **寅时（肺）**：肺朝百脉，气血重新分配于周身；
- **卯时（大肠）**：清晨排便的最佳时机；
- **午时（心）**：午间小憩养心。

## 记忆要点

1. **纳干看日**：阳干配阳腑、阴干配阴脏，五行完全一致（甲胆乙肝、丙小肠丁心……）；
2. **纳支看时**：肺寅大卯胃辰宫，从寅时肺经起按流注次序每时辰一经；
3. **三焦寄壬、包络寄癸**（纳甲），亥时三焦、戌时心包（纳支）；
4. **应用**：当令之时实泻其子、虚补其母；养生则"子时入睡、丑时深睡、寅时调息、卯时排便"。
