十二经脉按阴阳分为六条阴经（手三阴、足三阴）与六条阳经（手三阳、足三阳）。两者在脏腑络属、循行部位、走向交接、功能病候与气血多少上均有区别：

| 维度 | 阴经 | 阳经 |
| --- | --- | --- |
| 所连脏腑 | 脏（＋心包） | 腑 |
| 循行部位 | 四肢内侧（屈侧） | 四肢外侧（伸侧） |
| 走向 | 手三阴从胸走手；足三阴从足走腹胸 | 手三阳从手走头；足三阳从头走足 |
| 交接 | 足三阴与手三阴在胸腹交接 | 手三阳与足三阳在头面交接 |
| 表里络属 | 属脏、络腑 | 属腑、络脏 |
| 功能 | 藏精气、主内守 | 传化物、主卫外 |
| 病候 | 多内伤脏腑 | 多外感表证 |

## 一、所连脏腑之别

- **阴经属脏**：内连五脏（＋心包），主藏精气而不泻，为人体生命物质的贮藏之所；
- **阳经属腑**：内连六腑，主传化物而不藏，为水谷受盛传导的通道。

一脏一腑经脉络属构成表里，故阴经与阳经总是成对出现（见上篇《表里关系》）。

## 二、循行部位之别

阴经行于四肢**内侧**，阳经行于四肢**外侧**：

| 部位 | 前缘 | 中线 | 后缘 |
| --- | --- | --- | --- |
| 上肢内侧（阴） | 手太阴肺经 | 手厥阴心包经 | 手少阴心经 |
| 上肢外侧（阳） | 手阳明大肠经 | 手少阳三焦经 | 手太阳小肠经 |
| 下肢外侧（阳） | 足阳明胃经 | 足少阳胆经 | 足太阳膀胱经 |
| 下肢内侧（阴） | 足太阴脾经 | 足厥阴肝经 | 足少阴肾经 |

> 注：足三阴经在内踝上 8 寸以下有一处交叉——足厥阴肝经与足太阴脾经位置互换（前缘为厥阴、中线为太阴），8 寸以上恢复"太阴在前、厥阴居中"的常规排列。

## 三、走向与交接之别

十二经脉的走向与交接构成"阴阳相贯，如环无端"的循环：

- **手三阴经**：从胸走手，在手指端交于手三阳经；
- **手三阳经**：从手走头，在头面部交于足三阳经；
- **足三阳经**：从头走足，在足趾端交于足三阴经；
- **足三阴经**：从足走腹（胸），在胸腹部交于手三阴经。

可见：**阳经上行于头、阴经止于胸腹**，头为"诸阳之会"，胸腹为阴经交汇之所。

## 四、功能与病候之别

- **阳经主卫外**：阳气主外、卫外而为固，阳经受邪多表现为外感表证，如发热、恶寒、头身疼痛；
- **阴经主内守**：阴精藏于内、濡养脏腑，阴经病变多属内伤脏腑，如咳喘、心悸、腹胀、遗泄。

临床据此有"**阴病治阳、阳病治阴**"之训：内伤之病可从阳经取穴调治，外感之邪亦可从阴经辅以固本。

## 五、气血多少之别

《素问·血气形志》记载三阴三阳各经气血多少不同，是针灸刺法深浅、补泻（出血或出气）的依据：

| 经脉 | 气血 | 刺法宜忌 |
| --- | --- | --- |
| 阳明 | 多气多血 | 可出血气 |
| 太阳 | 多血少气 | 出血恶气 |
| 少阳 | 多气少血 | 出气恶血 |
| 太阴 | 多气少血 | 出气恶血 |
| 少阴 | 多气少血 | 出气恶血 |
| 厥阴 | 多血少气 | 出血恶气 |

> 《素问·血气形志》："刺阳明出血气，刺太阳出血恶气，刺少阳出气恶血，刺太阴出气恶血，刺少阴出气恶血，刺厥阴出血恶气。"

## 记忆要点

1. **脏阴腑阳**：阴经属脏、行内侧，阳经属腑、行外侧；
2. **走向**：手三阴胸→手，手三阳手→头，足三阳头→足，足三阴足→腹胸；
3. **功能**：阳主卫外、阴主内守，外感责阳、内伤责阴；
4. **气血**：阳明多气多血，太阳、厥阴多血少气，少阳、太阴、少阴多气少血。
