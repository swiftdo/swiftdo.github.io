## 十二经脉是什么

十二经脉是经络系统的主体，又称"十二正经"，包括：

- 手三阴经：手太阴肺经、手厥阴心包经、手少阴心经
- 手三阳经：手阳明大肠经、手少阳三焦经、手太阳小肠经
- 足三阳经：足阳明胃经、足少阳胆经、足太阳膀胱经
- 足三阴经：足太阴脾经、足厥阴肝经、足少阴肾经

每个名称由**手足 + 阴阳 + 脏腑**三部分组成，如"手太阴肺经"＝手（循行于上肢）＋太阴（阴气属性）＋肺（内属之脏）。

## 一、手足：循行部位

- **手经**：循行于上肢（手）的经脉，共六条；
- **足经**：循行于下肢（足）的经脉，共六条。

## 二、阴阳：三阴三阳

十二经脉的阴阳属性，源于《内经》对阴阳之气的三分法，即"三阴三阳"：

| 阴阳 | 名称 | 含义 |
| --- | --- | --- |
| 阳 | 太阳 | 阳气最盛 |
| 阳 | 阳明 | 阳气居中，"两阳合明" |
| 阳 | 少阳 | 阳气最少（初生之阳） |
| 阴 | 太阴 | 阴气最盛 |
| 阴 | 少阴 | 阴气次之 |
| 阴 | 厥阴 | 阴气最少，"阴尽阳生" |

> 《素问·至真要大论》："帝曰：愿闻阴阳之三也何谓？岐伯曰：气有多少，异用也。"

**脏腑表里配属**决定同名阴阳相配：脏为阴、腑为阳，一脏一腑相表里，其经脉便分属同一对阴阳（一阴一阳）。

| 脏（阴经） | 腑（阳经） | 阴阳配对 |
| --- | --- | --- |
| 肺 | 大肠 | 太阴 — 阳明 |
| 脾 | 胃 | 太阴 — 阳明 |
| 心 | 小肠 | 少阴 — 太阳 |
| 肾 | 膀胱 | 少阴 — 太阳 |
| 心包 | 三焦 | 厥阴 — 少阳 |
| 肝 | 胆 | 厥阴 — 少阳 |

## 三、脏腑：内属脏腑

十二经脉"内属于脏腑，外络于肢节"。每条经脉在体内连属一个脏腑：属脏者为**阴经**，属腑者为**阳经**。六脏（含心包）配六腑，恰好十二经。

### 五脏与六腑的区别

脏腑之分，本质在于"藏"与"泻"的功能之别，这是命名中"脏为阴、腑为阳"的根本依据：

| | 五脏 | 六腑 |
| --- | --- | --- |
| 成员 | 心、肝、脾、肺、肾（＋心包） | 胆、胃、大肠、小肠、膀胱、三焦 |
| 功能 | 藏精气而不泻 | 传化物而不藏 |
| 特点 | 满而不能实（贮藏精气，宜盈满） | 实而不能满（受盛传导，宜通畅） |
| 属性 | 阴 | 阳 |

> 《素问·五脏别论》："所谓五脏者，藏精气而不泻也，故满而不能实。六腑者，传化物而不藏，故实而不能满。"

- **五脏主藏**：贮藏精、气、血、津液等生命物质，不直接与水谷接触，故属阴，其经脉为阴经；
- **六腑主泻**：受盛、腐熟、传导、排泄水谷糟粕，以通降为用，故属阳，其经脉为阳经；
- 一脏一腑通过经络相互络属、构成**表里关系**（如肺与大肠相表里），这也是十二经阴阳配对（太阴—阳明、少阴—太阳、厥阴—少阳）的来源。

补充两点：

- **心包**：心之外围，代心受邪，故与五脏合称"六脏"，配属厥阴；
- **三焦**：六腑之一，为"决渎之官"，通行元气、运行水液，配属少阳。

### 脏腑与五行的关系

五行（木、火、土、金、水）是中医认识脏腑功能的又一框架。每个脏腑各配一行，相表里的脏与腑**同属一行**：

| 五行 | 五脏 | 六腑 | 五色 | 特性 |
| --- | --- | --- | --- | --- |
| 木 | 肝 | 胆 | 青 | 生发、条达 |
| 火 | 心 | 小肠 | 赤 | 温热、炎上 |
| 土 | 脾 | 胃 | 黄 | 化生、受纳 |
| 金 | 肺 | 大肠 | 白 | 肃降、收敛 |
| 水 | 肾 | 膀胱 | 黑 | 寒润、下行 |

> 心包与三焦属**相火**，与心（君火）同归于火行，其色亦为赤。

五色源于《素问·阴阳应象大论》"在色为青、赤、黄、白、黑"，是中医望诊的依据之一：如面色发青多责之于肝（木），面色萎黄多责之于脾（土），面色赤红多责之于心（火）。

五行之间通过**生克**维系脏腑间的动态平衡：

- **相生**：木 → 火 → 土 → 金 → 水 → 木（如肝木生心火：肝藏血以济心；脾土生肺金：脾运化以养肺）；
- **相克**：木 → 土 → 水 → 火 → 金 → 木（如肺金克肝木：肺气肃降以制约肝气升发）。

记法：**肝心脾肺肾，木火土金水**。

由此，一条经脉可以同时用阴阳与五行两个坐标来定位：如肺经——属阴（太阴）、属金，与大肠（属阳、属金）互为表里；五行属性一致的脏腑结为表里，阴阳属性则决定其经脉的阴经、阳经之分。

## 四、表里关系

**表里关系**指一脏一腑通过经脉相互络属而形成的配对：阴经属脏、络腑，阳经属腑、络脏，十二条经脉两两配对，构成六对表里。这是十二经脉"内属于脏腑"的具体体现。

| 表里对 | 阴经（属脏络腑） | 阳经（属腑络脏） | 阴阳配对 | 五行 |
| --- | --- | --- | --- | --- |
| 肺 — 大肠 | 手太阴肺经 | 手阳明大肠经 | 太阴 — 阳明 | 金 |
| 脾 — 胃 | 足太阴脾经 | 足阳明胃经 | 太阴 — 阳明 | 土 |
| 心 — 小肠 | 手少阴心经 | 手太阳小肠经 | 少阴 — 太阳 | 火 |
| 肾 — 膀胱 | 足少阴肾经 | 足太阳膀胱经 | 少阴 — 太阳 | 水 |
| 心包 — 三焦 | 手厥阴心包经 | 手少阳三焦经 | 厥阴 — 少阳 | 相火 |
| 肝 — 胆 | 足厥阴肝经 | 足少阳胆经 | 厥阴 — 少阳 | 木 |

### 表里关系的三个层面

**1. 生理配合**——一脏一腑功能相辅相成：

- **肺与大肠**：肺气肃降，助大肠传导糟粕；大肠通降，亦利肺气宣降；
- **脾与胃**：脾主升清、胃主降浊，纳运相济，共为"后天之本"；
- **心与小肠**：心火下移小肠，小肠泌别清浊，助心行血化液；
- **肾与膀胱**：肾司气化、主水，膀胱贮尿排尿，共主水液代谢；
- **肝与胆**：肝主疏泄以助胆汁分泌排泄，胆气通降亦利肝气疏达；
- **心包与三焦**：心包代心行令，三焦通行元气、运行水液。

**2. 病理互传**——表里脏腑病邪可相互影响：

- 肺热壅盛，可致大肠传导失常而便秘；大肠实热，腑气不通，亦可上迫于肺而喘咳；
- 肝气郁结，可横逆犯胃（肝木乘土），出现胁痛、泛酸；
- 心火亢盛，可下移小肠，见小便赤涩灼痛（"心移热于小肠"）。

**3. 治疗应用**——针灸取穴可表里互治：

- 肺病可取大肠经穴（如合谷），大肠病亦可取肺经穴（如列缺）；
- 胃病可取脾经穴（如公孙），脾病亦可取胃经穴（如足三里）；
- 表里配穴是针灸配穴的常用方法之一。

**循行上**，表里两经在四肢末端相接（如手太阴肺经在食指端交于手阳明大肠经），一阴一阳、一脏一腑由此贯通，构成完整的循环。

## 为什么叫"手太阴肺经"

以"手太阴肺经"为例拆解：

- **手**——这条经主要循行于上肢；
- **太阴**——它属于阴经，且阴气最盛（三阴之首）；
- **肺**——它内属肺脏，与大肠相表里。

其余十一经的命名逻辑完全相同：先看走手还是走足，再看属脏还是属腑、对应哪个阴阳层次，最后冠以所连属的脏腑名。

## 记忆要点

1. **脏为阴、腑为阳**，阴经属脏、阳经属腑，一一表里配对；
2. 阴经按"太阴 → 少阴 → 厥阴"（阴气由多到少），阳经按"阳明 → 太阳 → 少阳"排列于四肢；
3. 名称 = 手足 + 阴阳 + 脏腑，三者缺一不可，十二经名称即由此而来；
4. 六对表里可按五行记忆：**肺大肠金、脾胃土、心小肠火、肾膀胱水、心包三焦相火、肝胆木**，表里经生理相济、病理互传、治疗互用。
